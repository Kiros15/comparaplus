# ComparaPlus.net — V2 Professional

Homepage estática, responsive y preparada para desplegar directamente en Vercel.

## V2 incluye
- Rediseño premium orientado a comparación y conversión.
- Hero con dashboard visual de ejemplo.
- Navegación responsive con menú móvil.
- Categorías: Hipotecas, Préstamos, Cuentas, Tarjetas, Depósitos y Seguros.
- Bloque de opciones destacadas con estructura de comparador.
- CTA principal de comparación.
- Guías SEO y bloque de contenidos.
- Footer completo con arquitectura preparada para páginas legales.
- SEO básico: title, description, Open Graph y JSON-LD WebSite.
- Sin framework ni build: HTML/CSS/JS puro, listo para Vercel.
- Diseño preparado para incorporar afiliación, feeds/API de entidades, AdSense y páginas SEO por categoría.

## Antes de publicar ofertas reales
Los productos, tasas y condiciones mostrados en esta V2 son únicamente ejemplos visuales. Sustituir por datos reales y añadir las condiciones legales/comerciales correspondientes.

## Deploy en Vercel
1. Sube el contenido de esta carpeta a GitHub.
2. Importa el repositorio desde Vercel.
3. Framework Preset: Other (o detección automática).
4. No hace falta comando de build.
5. Publica en Production.
